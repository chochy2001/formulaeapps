# Formulae Pro

Formulae Pro es una aplicación de fórmulas matemáticas que te permitirá resolver problemas, aprender y estudiar matemáticas de una manera fácil y eficiente. Además, cuenta con videos e imágenes explicativas para que puedas entender mejor los conceptos y teorías.

## Funcionalidades

- Resolución de ejercicios matemáticos.
- Vídeos e imágenes explicativas.
- Descarga, impresión y compartir en PDFs.
- Agenda para apuntar tus tareas.
- Disponible para IOS, Android, Windows, Linux y Mac.

## Ejemplo de uso

1. Descarga e instala Formulae Math Pro en tu dispositivo.
2. Selecciona el tema que deseas estudiar.
3. Si no conoces el tema, puedes revisar los videos e imágenes explicativas para entender los conceptos.
4. Si ya conoces el tema, selecciona la opción para resolver ejercicios.
5. Una vez que hayas resuelto el ejercicio, puedes descargar, imprimir o compartir en PDF para tener una copia de tus respuestas.
6. Si tienes tareas pendientes, puedes agregarlas a la agenda para no olvidarlas.
